# LP-06 パックカルーセル

## 変更

ホームの大きな表紙を、横スワイプのカルーセルに変えた。選択中のパックが、所持数、収集率、引くボタン、図鑑リンクの対象になる。

- `scrollTargetBehavior(.viewAligned)` でスナップする。
- 選択中は枠を付け、Reduce Motion でなければ少し大きくする。動きを減らす設定では拡大アニメーションを付けない。
- ページドットは2枚以上のときだけ出し、タップでも選べる。VoiceOver ではカード側を読むので、ドットは読み上げない。
- 各カードは表紙と、今日引けるか消化済みかを出す。VoiceOver はパック名、引けるか、「全 n 枚中 m 枚目」を読む。
- カード幅は画面幅から左右 56pt を引き、最大 340pt。狭い画面では隣が少し見える。

新規のライブラリは足していない。
