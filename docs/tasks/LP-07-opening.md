# LP-07 パック開封

## 変更

ホームとパック詳細の「引く」は、同じ `PackOpeningView` を出す。抽選処理はここに一つだけある。

1. パック表紙が中央に出る。この段階で閉じると、その日の回数は消費しない。
2. タップ、または上へのスワイプで開封する。この瞬間に `DrawSession` が `DrawEngine.draw` を1回呼び、`ProgressStore.recordDraw` を1回呼ぶ。
3. カードが出る。
4. レアリティに応じた短い光を付ける。common は光なし。legendary が一番広い。色は既存のレア色と同じ。
5. 結果シートへ進む。

スキップは右上。封のままスキップしても抽選は1回で、すぐに結果へ進む。開封後のスキップは、保存し直さずに結果へ進む。Reduce Motion では待ち時間を無くし、開封の操作の直後に結果へ進む。

演出を閉じても、すでに `recordDraw` したカードと最終ドロー日は残る。結果シートへの受け渡しは、カバーを閉じてから行う。

パック詳細にあった 350ms 待ちと、その場での `DrawEngine.draw` は外した。
