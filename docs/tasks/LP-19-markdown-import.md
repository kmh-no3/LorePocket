# LP-19 Markdownインポート

## 変更

Obsidian形式（frontmatter と `## 格言` / 背景 / Topics）はそのまま読める。加えて次を読む。

- `kind` と `source` / `sourceTitle`
- `## 本文` と `## 解説`（長文）
- `## 引用`、`## 作品の背景`、`## AI分析`（進捗の `analyses` へ。カード本文には混ぜない）
- それ以外の見出しと、未知の frontmatter はカードのセクションになる
- 失敗したファイル名と理由（格言または本文が空、UTF-8で読めない）を返す
- 1枚も作れないときはパックを書き出さない。一部だけ失敗したときは成功分を保存し、失敗一覧を出す

所持カードはインポートでは消さない。分析の書き込みは `setAnalysis` で、考察と所持を残す。
