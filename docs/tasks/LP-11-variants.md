# LP-11 別柄

## 変更

カード詳細の所持バリアントを、パック定義の順に並ぶ横チップにした。所持している柄をタップすると、上のカード面が切り替わる。未所持は錠を付けて選べない。選んだ柄のレアリティと入手日をチップの下に出す。

セグメントの切替と、所持分だけの一覧は外した。未所持のカードは「未所持」のまま。
