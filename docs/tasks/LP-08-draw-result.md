# LP-08 抽選結果

## 変更

結果シートを、スクロールする大きいカードにした。

- カード面を強調し、引用が長いときは8行で切る。画面の高さを固定していない。
- NEW CARD と NEW VARIANT は残す。横に収まらないときは縦に並べる。
- レアリティの枠と光は、既存のレア色を使う。common は枠を足さない。
- 人物、作品名、背景、Topics を出す。背景は180字まで。解説や追加見出しの全文はここには並べず、「全文はカードの詳細で読めます」と出す。
- 「このカードの詳細」は、考察と取り込み分析を分けたままの `CardDetailView` へ進む。
- 「図鑑を見る」はそのパックの図鑑へ進む。
- 「閉じる」はシートを閉じ、ホームタブへ戻す。
- Reduce Motion のときは出現の拡大を付けない。
