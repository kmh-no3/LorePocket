# LP-12 展示ケース（リセット・ライト・台座）

## 変更したこと

3D展示のプロトタイプに、初期状態へ戻す操作と、ライトおよび台座の切り替えを足した。ドラッグによるY軸回転と、ケース3種（clear / smoky / gold）の素材はそのまま残している。カードの白い板、メッシュの寸法、ドロー規則、進捗の保存は変えていない。

- **リセット**: ボタンの表示は「リセット」。`rotationY = 0`、ケースは clear、ライトは standard、台座は graphite に戻す。`accessibilityReduceMotion` がオンのときは、回転を含めてその場で値を入れる。オフのときはケース・ライト・台座はすぐ戻し、回転だけ 30 ミリ秒間隔の 12 段階（待ちは 11 回なので約 0.33 秒）で 0 へ近づける。蓄積した角度は ±π に畳んでから戻すので、ドラッグを繰り返したあとに何周も回らない。ドラッグを始めると、その回転の補間は止める。
- **ライト**: soft / standard / bright。standard は従来どおり intensity `2000`、attenuation radius `2`。soft は `600` / `3`、bright は `6000` / `3.5`。soft と bright の数値は相対的なプリセットであり、画面で明るさを合わせていない。
- **台座**: メッシュ（`[0.55, 0.08, 0.38]`、cornerRadius `0.02`）はそのまま。graphite は従来の dark gray、walnut は brown、stone は light gray。
- **選択中の見た目**: ケースの選択中だけ `borderedProminent`。ライトと台座も、今の値が分かるように同じ選択表示にしている。
- **シーン更新**: `ShowcasePresentation`（ケース・ライト・台座）をまとめて比較してから反映する。ケースが同じという理由だけでは処理を戻さない。ライトだけ、台座だけの変更もマテリアルとライトへ届く。
- **読み上げ**: 回転は「回転」、ケースは「ケース」、ライトは「ライト」、台座は「台座」。リセットのアクセシビリティラベルは「リセット」。
- `ShowcaseView(card:)` と `CardModel` の `init(id:title:)` / `init(card:)` はそのまま。
